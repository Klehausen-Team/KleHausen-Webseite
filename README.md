# KleHausen - Discord Community Website

Eine moderne, responsive Webseite für die KleHausen Discord Community und ihre Projekte.

## 🎯 Über das Projekt

KleHausen ist eine kreative Discord Community von 4-8 Content Creators, die gemeinsam innovative Projekte entwickeln und Content produzieren. Diese Webseite dient als zentrale Anlaufstelle für die Präsentation unserer Projekte und als Verbindung zu unserer Community.

## 🚀 Unsere Projekte

### 💻 Web-basierter Desktop
Ein innovatives webbasiertes Desktop-System, das eine vollständige Desktop-Erfahrung im Browser bietet.
- **Status**: Aktiv in Entwicklung
- **Technologien**: HTML5, CSS3, JavaScript, Node.js

### 🎮 Minecraft Server
Unser eigener Minecraft Server mit custom Features und Plugins für die Community.
- **Status**: Entwicklung pausiert
- **Technologien**: Java, Spigot, MySQL, Docker

### 📱 Content Creator Gruppe
Unsere kleine aber feine Content Creator Gruppe produziert gemeinsam verschiedensten Content.
- **Status**: Aktiv
- **Plattformen**: YouTube, Twitch, Discord, Social Media

## 🎨 Design & Features

- **Akzentfarbe**: Orange (#ff7b00) - die charakteristische Farbe aller KleHausen Projekte
- **Responsive Design**: Optimiert für alle Geräte (Desktop, Tablet, Mobile)
- **Modern UI**: Dunkles Theme mit Orange-Akzenten
- **Interaktive Elemente**: Animationen, Hover-Effekte und smooth scrolling
- **Accessibility**: Keyboard-Navigation und screen reader freundlich

## 🛠️ Technologie Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Custom CSS mit CSS Grid und Flexbox
- **Icons**: Font Awesome 6
- **Responsive**: Mobile-First Approach
- **Performance**: Optimierte Ladezeiten und lazy loading

## 🚀 Installation & Setup

1. **Repository klonen**
   ```bash
   git clone https://github.com/Klehausen-Team/KleHausen-Webseite.git
   cd KleHausen-Webseite
   ```

2. **Lokaler Server starten**
   ```bash
   # Mit Python
   python -m http.server 8000
   
   # Mit Node.js (npx)
   npx serve .
   
   # Mit PHP
   php -S localhost:8000
   ```

3. **Im Browser öffnen**
   ```
   http://localhost:8000
   ```
